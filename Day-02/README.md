# Day 2 - Basic Logic Gates in Verilog

## Objective

Learn Verilog operators and implement basic combinational logic gates.

## Topics Covered

- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate
- XNOR Gate

## Tools Used

- Visual Studio Code
- Icarus Verilog
- GTKWave
- Git & GitHub

## Files Included

- Verilog source code (.v)
- Testbench (.v)
- Waveform (.vcd)

## Learning Outcome

After completing Day 2, I learned:

- Verilog logical operators
- Writing modules
- Writing testbenches
- Running simulations
- Viewing waveforms in GTKWave
- Verifying logic gate truth tables
